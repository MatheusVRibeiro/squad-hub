- `npm run dev` — Vite dev server → http://localhost:5173
- `npm run build` — build de produção (TanStack Start)
- `npm run preview` — preview do build (porta 4173 — fora da whitelist CORS padrão do backend; usar `FRONTEND_URL="http://localhost:5173,http://localhost:4173"` no backend)
- `npm start` — `node server.js` (servidor de produção)
- `npm test` — Vitest (services mockando `./api`)
- `npm run lint` — ESLint (0 erros / 7 warnings aceitos: react-refresh em shadcn/ui + AuthContext)

## Padrões do Projeto

- **Envelope da API**: SEMPRE desembrulhar `{sucesso, message, dados}` — `api.get<{sucesso: boolean; dados: T}>` → usar `data.dados`; conferir shape REAL do controller com curl antes de tipar
- **Contrato**: backend devolve camelCase nos controllers (ex.: notificações `{id, type, title, description, createdAt, read, link}`) — EXCEÇÃO: `GET /projetos/:id` mantém `criador_id`/`criador_nome` em snake_case (mapear `criador_id` → `creatorId` no service); `members[].id` é string
- **Fallbacks**: PROD lança erro em falha (estado de erro visível na UI); DEV mantém fallback mock/localStorage (gate `import.meta.env.DEV`) — mocks isolados em `src/services/mocks.ts`
- **Guarda SSR**: services chamados por `useQuery` rodam no servidor — `if (typeof window === "undefined") return [];` no topo (sem token/localStorage no SSR)
- **useQuery pós-migração p/ throw**: destructure `{isLoading, isError, error, refetch}` e renderizar 4 estados (loading/erro/vazio/conteúdo) — `{isLoading || !data ? <Skeleton/> : ...}` vira skeleton ETERNO
- **Rotas novas**: criar `src/routes/<nome>.tsx` com `createFileRoute` + REGENERAR `routeTree.gen.ts` rodando `vite dev` (NÃO editar `router.tsx` nem o `.gen` à mão)
- **IDs por id, nunca por nome**: `isOwner`/`isMember` comparando `Number(data.creatorId) === Number(user?.id)`
- **Arquivos novos do `write_file` saem CRLF** — com `endOfLine: "auto"` no `.prettierrc` o lint não quebra; converter p/ LF só se os vizinhos forem LF
